# DAVIX — Personal Website

A dark, editorial personal website for Davix, founder and CEO of PRETHIM.

## Visual direction
- Deep earth palette: `#14110D`, `#1B1712`, `#2A241B`
- Ivory typography with restrained copper accents: `#C97C3E`
- Slow fades from darkness; no abrupt entrance animations
- Editorial serif headlines; no monospace or generic sans-serif utility styling
- Oversized background forms are atmospheric, not section numbering
- Responsive layout and reduced-motion support

## Add the portrait
